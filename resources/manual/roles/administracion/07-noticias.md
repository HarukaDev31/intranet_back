# Noticias

## Para qué sirve

Leer comunicados y novedades publicadas para el equipo.

## Cómo usarlo

1. Entra a **Noticias**.
2. Revisa el listado (tipo, fecha, resumen).
3. Lee el contenido completo.
4. Si hay **Ver más**, úsalo para ir al módulo relacionado.

## Qué ocurre después

Te enteras de cambios de sistema o avisos internos sin depender del correo.

## Si algo no funciona

- Lista vacía: aún no hay publicaciones.
- Un enlace no abre: avisa a Soporte TI.
