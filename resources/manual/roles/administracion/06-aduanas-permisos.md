# Aduanas — Permisos y consulta

## Para qué sirve

Consultar permisos y información aduanera relacionada cuando un caso administrativo lo requiere (sin reemplazar el trabajo de Documentación).

## Cómo usarlo

1. Entra a **Aduanas → Permisos** (y otras opciones de Aduanas si las ves).
2. Busca el trámite y filtra por estado.
3. Abre el detalle para revisar la información.
4. Si tu pantalla permite crear o editar, hazlo solo cuando corresponda a tu proceso; si no, deriva a Documentación/Coordinación.

## Qué ocurre después

La consulta te orienta para verificación o respuesta interna. Los trámites formales los cierran las áreas operativas.

## Si algo no funciona

- No puedes crear permisos: esperado en muchos perfiles de consulta.
- Duda de una norma: confirma con Documentación antes de comprometer una respuesta al cliente.
