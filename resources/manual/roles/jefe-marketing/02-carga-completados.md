# Carga consolidada — Completados

## Para qué sirve

Consultar cargas ya cerradas y revisar su información histórica.

## Cómo usarlo

1. Entra a **Carga Consolidada → Completados**.
2. Busca o filtra la carga que necesitas.
3. Ábrela para consultar el detalle (sin alterar el flujo de una carga abierta, salvo que el sistema te permita alguna acción puntual).

## Qué ocurre después

Sirve para consultas, reportes y seguimiento de cargas terminadas.

## Si algo no funciona

- Si no aparece, prueba otro año o limpia filtros.

> Menú: **Carga Consolidada → Completados**
