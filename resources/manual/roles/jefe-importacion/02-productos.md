# Aduanas — Productos

## Para qué sirve

Consultar el historial de productos importados para orientar cotizaciones o trámites.

## Cómo usarlo

1. Entra a **Aduanas → Productos**.
2. Busca y filtra el producto.
3. Revisa el detalle o exporta si el botón está disponible.

## Qué ocurre después

Te ayuda a responder al cliente con información de productos ya trabajados.

## Si algo no funciona

- Producto no encontrado: prueba otro término o pide apoyo a Documentación.
