# Mis reintegros / Viáticos

## Para qué sirve

Registrar y dar seguimiento a tus reintegros o viáticos.

## Cómo usarlo

1. Entra a **Viáticos / Mis Reintegros**.
2. Revisa pendientes o completados según el submenú.
3. Crea un nuevo registro si el botón está disponible y adjunta evidencias.

## Qué ocurre después

El área responsable revisa y cambia el estado hasta completarlo.

## Si algo no funciona

- Falta evidencia: el sistema o el revisor te lo pedirán.

> Menú: **Mis Reintegros → Mis Reintegros**
