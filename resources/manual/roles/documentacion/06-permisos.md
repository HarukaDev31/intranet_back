# Aduanas — Permisos

## Para qué sirve

Revisar trámites/permisos aduaneros asociados a productos o clientes.

## Cómo usarlo

1. Entra a **Aduanas → Permisos**.
2. Busca y filtra por estado.
3. Abre el registro para consultar el detalle.

## Qué ocurre después

Sirve para seguimiento y consulta; altas/ediciones pueden estar limitadas a otros roles.

## Si algo no funciona

- Sin permiso para crear/editar: avisa a Documentación o Coordinación.

> Menú: **Aduanas → Permisos**
