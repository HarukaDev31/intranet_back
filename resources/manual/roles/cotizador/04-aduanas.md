# Aduanas (consulta para cotizar)

## Para qué sirve

Consultar información aduanera que te ayuda a cotizar con criterio: productos importados, regulaciones, permisos y boletín químico.  
**No reemplaza** el trabajo formal de Documentación o Coordinación; te orienta para asesorar al cliente.

## Productos

1. Entra a **Aduanas → Productos**.
2. Verás el **Historial de productos importados**.
3. Busca y filtra según necesites.
4. Puedes exportar si el botón está disponible.

> Como Cotizador no importas el catálogo de productos (eso lo hace Documentación). Tú consultas.

## Regulación aduanera

1. Entra a **Aduanas → Regulaciones**.
2. Usa las pestañas: **Antidumping**, **Permisos**, **Etiquetado** y **Doc. Especiales**.
3. Abre el detalle de lo que necesites para tu cotización.

La creación de nuevas regulaciones suele estar reservada a Documentación.

## Permisos

1. Entra a **Aduanas → Permisos**.
2. Busca el trámite y filtra por **Estado** si hace falta.
3. Consulta la información.

Como Cotizador normalmente **no** creas, editas ni eliminas permisos.

## Boletín químico

1. Entra a **Aduanas → Boletín Químico**.
2. Busca por cliente o consolidado.
3. Si tu permiso lo permite, usa **Nuevo** para registrar un boletín.

## Qué pasa después

Usas esta información al armar la cotización o al responder dudas del cliente. Los trámites formales los continúan los equipos de Documentación / Coordinación.

## Problemas frecuentes

- **No encuentro el producto:** prueba otro término de búsqueda o pide apoyo a Documentación.
- **No puedo crear un permiso:** es esperado en Cotizador.
- **Duda de una regulación:** verifica la ficha y, si hay duda, consulta al área especializada antes de comprometer al cliente.
