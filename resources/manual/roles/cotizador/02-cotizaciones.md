# Cotizaciones (Calculadora)

## Para qué sirve

Armar cotizaciones de importación con costos y documentos, antes o junto a la carga consolidada.

## Línea de tiempo en pantalla

1. Menú → **Cotizador** (listado **Cotizaciones**).
2. Busca / filtra (fechas, campaña, estado, vendedor, vinculación proveedores).
3. Pulsa **Crear Cotización** (o edita una que no esté CONFIRMADO).
4. Completa la calculadora en orden: **Datos → Carga → Costo → Terminar**.
5. Usa **Siguiente** / **Anterior** y al final **Finalizar**.

## Estados que verás

**PENDIENTE** → **COTIZADO** → **CONFIRMADO**  
Para pasar a COTIZADO suele hacer falta contenedor asociado.

## Otras acciones del listado

**Gestionar tarifas de calculadora**, exportar, duplicar, vincular proveedores, ver **Documentos asociados**, ir al contenedor.

## Si algo no funciona

- No finaliza: faltan datos del cliente o costos.
- No edita: ya está CONFIRMADO.
- No pasa a COTIZADO: revisa el contenedor vinculado.
