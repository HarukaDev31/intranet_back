# Chat / WhatsApp (Coordinación)

## Para qué sirve

Atender el buzón de WhatsApp de coordinación con clientes o contactos.

## Cómo usarlo

1. Entra a **Chat** (bandeja WhatsApp).
2. Selecciona una conversación.
3. Responde, adjunta o usa las acciones disponibles en la bandeja.

## Qué ocurre después

La conversación queda actualizada para el equipo de coordinación.

## Si algo no funciona

- No ves chats: permisos o sincronización del canal.

> Menú: **Chat → Chat**
