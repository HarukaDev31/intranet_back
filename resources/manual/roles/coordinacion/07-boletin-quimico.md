# Aduanas — Boletín químico

## Para qué sirve

Registrar o consultar boletines químicos vinculados a clientes/consolidados.

## Cómo usarlo

1. Entra a **Aduanas → Boletín Químico**.
2. Busca por cliente o consolidado.
3. Usa **Nuevo** si tu rol lo permite.

## Qué ocurre después

El boletín queda disponible para el equipo que continúa el trámite.

## Si algo no funciona

- No aparece **Nuevo**: tu rol solo consulta.

> Menú: **Aduanas → Boletin Quimico**
